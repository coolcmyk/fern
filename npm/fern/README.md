# Fern

Native Rust CLI for running robotics simulations on cloud compute.

## Install with Bun

```console
bun install --global @coolcmyk/fern
fern --help
```

Or run it without a permanent installation:

```console
bunx @coolcmyk/fern --help
```

Fern loads `RUNPOD_API_KEY` from the process environment or a `.env` file in
the current project.

Project source and documentation:
[github.com/coolcmyk/fern](https://github.com/coolcmyk/fern).
